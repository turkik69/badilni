# بادلني

تطبيق عربي للمبادلة المباشرة بين المستخدمين، يعمل كتطبيق PWA على GitHub Pages.

## البنية

- الواجهة: HTML/CSS/JavaScript بدون أدوات بناء.
- البيانات: Firebase Realtime Database تحت المسار المستقل `/badilni`.
- الجلسة: رقم هاتف + رمز دخول شخصي مشفّر، مع جلسة محلية على الجهاز.
- الصور: تُضغط في المتصفح قبل حفظها مع بيانات الغرض.
- الاستضافة: GitHub Pages.

## الوظائف

- ملفات المستخدمين ومحفظة نقاط ابتدائية.
- إضافة الأغراض والصور والفئات والحالة والقيمة التقديرية.
- مطابقة تلقائية ثنائية الاتجاه حسب الفئة المطلوبة.
- عروض مباشرة، تفاوض، محادثة، اتفاق، تأكيد استلام من الطرفين، وإلغاء.
- حجز نقاط فرق القيمة وإعادتها عند الإلغاء.
- تقييمات وبلاغات وإشعارات داخلية.
- تثبيت كتطبيق والعمل من ذاكرة التخزين المؤقت بعد الزيارة الأولى.

## التشغيل المحلي

شغّل أي خادم ملفات ثابتة من مجلد المشروع، ثم افتح `index.html` عبر الخادم. لا يتطلب المشروع npm أو عملية build.

## البيانات

جميع بيانات هذا التطبيق معزولة عن تطبيق دوري الأبطال داخل مساحة `badilni` في Firebase. ملف `firebase-store.js` هو طبقة البيانات الوحيدة، ولا توجد تبعية على Supabase.
# شعارات المركبات

ملفات `brand-logos/` مأخوذة من [Simple Icons](https://github.com/simple-icons/simple-icons) لتوضيح شركة المركبة في نتائج البحث ونموذج الإعلان. شعارات الشركات علامات لأصحابها، واستخدامها هنا للتعريف بالعلامة فقط؛ بادلني غير تابع لها. تُعرض أسماء نصية للشركات التي لا تتوفر لها ملفات شعار محلية.
